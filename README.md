Events Montenegro

A responsive event discovery website for Montenegro, developed as a collaborative frontend project.

[Live Demo](https://jelena982.github.io/events-project/)

About the Project

The website allows users to explore events and activities in Montenegro. It was created to practice frontend development, responsive web design, and teamwork.

Technologies
HTML5
CSS3
JavaScript
Responsive Web Design
Authors

This project was collaboratively developed by Jelena Damjanović (@jelena982) and @prodanovicaleksej.

Both authors worked together on the website structure, styling, JavaScript functionality, content, and responsive design.
